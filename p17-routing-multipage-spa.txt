Once the application is up and running then we give the user the illusion of multiple pages.

Angular lets us implement client side routing 

Routing is provided via app.config.ts. Routes needs to be added to the providers array. 

export const appConfig: ApplicationConfig = {
  providers: [
    provideBrowserGlobalErrorListeners(),
    provideRouter(routes)
  ]
};

The the routed will get defined in 
app.routes.ts file

export const routes: Routes = [];

Then add <router-outlet /> to the app.html
